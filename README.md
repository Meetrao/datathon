# Automated Insight Analyst

A zero‑configuration pipeline that ingests any CSV, automatically detects column types, cleans the data, surfaces ML‑driven patterns, generates charts, and produces a plain‑language summary—all rendered in an easy‑to‑read dashboard.

## Quick start
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Project structure
- `app.py` – Streamlit entry point
- `modules/` – Pure‑Python processing modules
- `requirements.txt` – Dependencies
- `PROJECT_DOCUMENTATION.md` – Full design doc (the one you provided)
